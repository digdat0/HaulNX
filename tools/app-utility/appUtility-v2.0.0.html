Transfer over Wi-Fi

Both devices on the same network. On the Switch, open the matching receive screen — it shows IP:PORT/CODE to type below. The IP and port are remembered; the code changes each time the receive screen opens.
Pushes the collection you're editing on the Collection tab to the console. On the Switch, open Settings › PC Sync › Import collection — it shows the address to type above — then hit Send. Leave that screen open: it stops listening once the file arrives, and you confirm the import there.
Loads the collection the console is currently running into the Collection editor, so you can edit it and send it back. Open the same Import collection screen on the Switch for the address, then hit Get from Switch.
Pushes a game file into a console's installed folder — handy for a ROM you already have on your PC. On the Switch, open the Installed tab, highlight the console, press Y for its ROM folder, and choose Receive from PC — it shows the address to type above. It goes into whichever console you opened that screen from, so pick the right one there; then hit Send and confirm on the Switch if it would replace a file already there.
Pushes a freshly built HaulNX .nro to the console — no USB cable needed, and the same version as installed is fine. On the Switch, open Settings › Updates › Update app over Wi‑Fi; you confirm the install there and restart to switch to the new build.

Device inventory

On the Switch, open Settings › PC Sync and turn on Device inventory server — it shows the IP:PORT/CODE to type below, and stays on until you turn it off. Read-only: nothing here writes to the console.
